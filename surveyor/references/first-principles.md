# 第一性裁决 — probing 手册

> 配套 `SKILL.md` 第 1 节。第一性裁决不是「我偏好什么」，而是**从终局目的一层层追问到不能再约简**的因果判断。本手册给出每四件事的提问钩子与「伪第一性」识别。

---

## 1. 终局目的

**提问钩子：**
- 这个系统/改动最终要改善**哪一个可观察的结果**？（不是「改善什么」，而是「改善哪个**结果/裁决**」）
- 如果有人提议一个无关优化，我能用这条终局目的**当场拒绝**它吗？不能 → 目的还不够具体。
- 一年后回看，用什么**事实**判断这次做对了还是做错了？

**伪终局目的（不可证伪套话，命中即重写）：**
- 「完善系统」「优化体验」「提升效率」「让它更好用」。
- 把**手段**当目的（「用上 XX 技术」「统一成 XX」）。
- 把**过程**当目的（「跑通流程」「覆盖更多」）。

> 合格判据：终局目的具体到「能据此拒绝一个无关优化」。

---

## 2. 当前主矛盾

**提问钩子（反事实判别器）：**
- *若本次只能修一项，修哪项最能改变终局结果？*（注意：在**可作用**的项里取；那个影响最大但本次动不了的因子，列入边界/环境约束，不算主矛盾。）
- 哪项一旦错，会让其它优化**整体失效**？（= 根基项）
- 哪项位于**因果上游**、错误会向最多下游传播？
- 哪项会**跨会话复发、难逆、或产生最大长期债**？

**操作：** 证据足够时，由此**具名一个**当前主矛盾。证据不足时保留竞争解释，选择能区分关键假设的下一步取证；不要把「尚不能判断」写成「已确认无支配项」。其它影响进入边界与次要项，**不因没排第一而消失**。

**合法出口（防死循环）：** 证据充分时，可以裁决为单一主矛盾、具名说明耦合机制的耦合并列，或有依据的无支配项。反事实判别器帮助提出和比较解释，不替代事实验证；证据不足时保留待验证判断，不等于无支配项，也不算形状错误。

**陷阱：**
- **平铺同权**：不比较依据，只列出一堆「都重要」；证据不足时也不选择能区分解释的下一步。
- **并列伪装的耦合**：声称两项并列，须说明它们为何**因果耦合、无法分开裁决**；说不出 → 不冒称耦合；按证据排主次，不足则先取证。
- 反事实答案若撞上**不可交换边界** → 边界优先，主矛盾让位。

---

## 3. 不可交换边界

**提问钩子：**
- 哪些性质即使能换来**很大的局部便利**也不能牺牲？
- 如果将来某个实现想用「更快/更省/更自动」换掉它，我会**坚决拒绝**的是哪条？

**常见不可交换边界（按域挑选，不是清单）：**
- **单一真源** —— 同一事实不允许两处各自为政的副本。
- **语义不被实现改写** —— 实现/降级不得偷偷改变任务语义、对象身份、证据等级。
- **真实身份不冒充** —— 不用代理/占位/近似冒充拿不到的真实对象（如：用测试数据冒充真实生产数据、用匿名身份冒充需登录的真实用户、用历史快照冒充实时状态）。
- **人的最终裁决权** —— 在用户授权范围内承担执行与判断；保留人的知情与最终裁决权，不以自主执行越过授权。

> 边界与实现的区别：**实现可换，边界不可偷换**。判断一条是不是边界：换掉它省下的麻烦，值不值它守住的东西。

## 4. 优先级依据

**候选影响轴（不是固定等权打分表）：**

| 轴 | 问什么 |
|---|---|
| 终局效果 | 对终局结果的直接拉动多大？ |
| 因果上游性 | 它错了会带垮多少下游？ |
| 波及面 / 复发频率 | 影响多少案例？会不会反复犯？ |
| 失败代价 | 做错了多严重？多难发现？ |
| 长期防腐 / 单一真源 | 会不会引入第二个真源、腐化现有纪律？ |
| 长期演进 / 可扩展 | 会不会堵死未来的扩展、增加迁移成本？ |
| 可逆性 | 改错了能不能退回来？ |
| 运行环境现实 | 当前环境真的支撑这个方案吗？ |
| 复杂度 / 上下文债 | 会增加多少理解与维护负担？ |

**铁律：不预设谁永远第一。** 长期防腐很重要，但不是永远第一；**现场判断当前哪个轴最支配结果**，并**明说**本次排序受哪几个轴支配。

---

## 行动裁决

先比较做、不做、少做、替代方案，再给必要改动排主次。审计发现不是自动整改授权；收益、风险、授权与包含验证、返工、异常、协调和认知负担的整体成本共同决定是否行动。

选择因果边界内的最小完整改动；把双源、耦合、静默路由和迁移成本计入长期账。只披露会影响用户判断的暂不处理项。执行成本或能力变化后，复查旧分工与交接是否仍必要；共同形成意图的互动不可一概当作摩擦删除。
