# Surveyor 交付前自检清单

> 一页可打印。在本次因果边界内自检，深度按风险与决策需要调整。**只有影响目标、边界或裁决的缺口才阻塞相关动作；只重审受影响范围。**
>
> **性质声明：这是自觉自检，不是 gate / lint / CI 门禁。** 它由人/模型自觉执行，绝不固化成代码强制——一旦做成引擎，就从「帮助想全」退化成「假装想全」（这正是本方法点名禁止的退化）。

---

## A. 第一性裁决
- [ ] **终局目的**具体到「能据此拒绝一个无关优化」，不是套话。
- [ ] **当前主矛盾**落到**一个**（或具名的**耦合并列** / **无支配项**），且是**本次可作用**的项，说明了为什么它最上游/波及最大/失败代价最高。
- [ ] **不可交换边界**列清，且能区分「边界（不可换）」与「实现（可换）」。
- [ ] **优先级依据**明说了本次受哪几个轴支配，没把长期防腐当成永远第一。
- [ ] 主矛盾与边界冲突时，**边界优先**。

## B. 逻辑空间
- [ ] **原子对象**单一，没在格里偷混不同对象。
- [ ] 每根**逻辑轴只回答一种问题**；先轴内 MECE，再组合正交轴。
- [ ] **关系形状**标清：分区/叠乘/约束/依赖/优先级/override；没把借道当同义、没把约束误标成正交（换一轴的值会不会强迫另一轴变？会→不是正交）。
- [ ] 每个合法原子案例有**唯一 owner**，或显式 `N/A`/`UNKNOWN`/`residual`（这是覆盖论证非数学保证，未覆盖处已显式标出）。
- [ ] **互补最小**：删掉任一项会有案例失 owner；无两项回答同一问题（**刻意冗余**如备援/双活已显式声明为冗余设计）。
- [ ] **相互干扰**（耦合/替代/侵蚀/长期副作用）已标出。

## C. 反例审查
- [ ] **双命中**：构造边界案例，无同时落入两个同级 owner 的。
- [ ] **零命中**：无被表格/「其它」静默省略的合法案例。
- [ ] **边界切换**：每个分区边界的切换条件可观察且已写明。
- [ ] **失败穿透**：降级/fallback 不偷换任务语义、对象身份、证据等级。

## D. 交付与收敛
- [ ] 已比较做、不做、少做、替代方案；整体成本包含验证、返工、异常、协调与认知负担。
- [ ] 改动范围因果完整；发现不自动变成整改或全局治理。
- [ ] 已用与风险相称的证据验证目标与关键边界，未把未验证写成通过。
- [ ] 用户能复述裁决、关键依据、重要风险和需其拍板之处；不强制标题与满槽。
- [ ] 目标达到、必要验证通过、剩余不确定性不足以改变裁决时停止。

---

**三条贯穿立场复查：**
- [ ] 整体 > 零件：每个部件都问「该不该存在、属哪平面、能否从终局推出」。
- [ ] 删 > 加：新阶段/入口/目录默认有罪，合并优于扩张、指针优于复制（**前置：已有复杂度存量的系统**；绿地项目默认有罪的是「无 owner、无从终局推出的加」）。
- [ ] 约束形状 ≠ 编排思考：没把本方法固化成 schema/lint/gate/硬流水线。
