# surveyor

看清全局，溯本清源，沿假设深入验证。遇到失败就回退，已知路径走尽后继续检查并拓展问题树。

这是一个跨域判断 skill。它适用于架构、方案评估、复杂排障和探索停滞。简单、已明确的执行任务直接完成。

## 三个思路方向

| 方向 | 要解决的问题 | 具体 demo |
|---|---|---|
| 看清全局 | 逻辑空间遗漏了什么，分支之间是什么关系？ | [取证空间的覆盖](surveyor/examples/01-global-space.md) |
| 溯本清源 | 用户提出的手段，是否服务其真实诉求？ | [从加并发追溯诉求](surveyor/examples/02-real-intent.md) |
| 深入搜索 | 如何验证节点假设、回退分支并拓展树？ | [报表迟到的排障](surveyor/examples/03-depth-first-search.md) |

三个方向相互校正。全局空间帮助发现遗漏，真实诉求决定根节点，验证结果推动回退和扩树。

默认沿最有价值的分支做深度优先搜索。每个关键节点都要有可检验的假设和否定条件。证据否定假设后，回退并选择剩余分支。

目标未达且已知树耗尽时，优先怀疑树不完整。检查根问题、遗漏的阶段、错误拆分和组合原因，再继续搜索。已知树耗尽不等于现实无解。

扩树须增加新的解释或可检验路径。已达到目标，或已有证据证明约束冲突时，如实收束。访问受阻也不能冒充假设已被否定。

## 文件入口

- [SKILL.md](surveyor/SKILL.md)：三个方向及其联动规则。
- [逻辑空间](surveyor/references/logic-space.md)：建树、关系与覆盖检查。
- [真实诉求](surveyor/references/real-intent.md)：核验前提和澄清目标。
- [深度优先搜索](surveyor/references/depth-first-search.md)：节点状态、回退和扩树。
- [自检清单](surveyor/references/checklist.md)：交付前的关键检查。

三个 demo 均包含输入、证据、判断和反例。演示数据均为虚构，不能作为真实系统的验证结果。

## 使用与安装

将完整的 `surveyor/` 目录放入目标环境的技能目录。替换已安装版本前保留备份。

Claude Code 可放在 `~/.claude/skills/surveyor`。其他环境按其技能加载方式安装。本方法不依赖特定工具。
