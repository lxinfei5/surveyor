# surveyor

看清全局，溯本清源，沿假设深入验证，通过分工协作共同校正。遇到失败就回退，已知路径走尽后继续检查并拓展问题树。

这是一个跨域判断 skill。它适用于架构、方案评估、复杂排障和探索停滞，也适用于从新旧材料发现问题的开放探索。简单、已明确的执行任务直接完成。

四个方向共同检查任务与环境是否匹配：开放探索或工作阶段变化时，按需审视项目规则、工具和上下文是否提前收窄问题。发现不匹配就指出具体来源与影响，提出保留保护职责的最小适配；按有效授权执行并验证实际产物，未获授权的修改先给出具体建议。无需每次审计整个项目，也不能以换环境绕过有效限制。

## 四个思路方向

| 方向 | 要解决的问题 | 具体 demo |
|---|---|---|
| 看清全局 | 逻辑空间遗漏了什么，分支之间是什么关系？ | [取证空间的覆盖](surveyor/examples/01-global-space.md) |
| 溯本清源 | 用户提出的手段，是否服务其真实诉求？ | [从加并发追溯诉求](surveyor/examples/02-real-intent.md) |
| 深入搜索 | 如何验证节点假设、回退分支并拓展树？ | [报表迟到的排障](surveyor/examples/03-depth-first-search.md) |
| 分工协作 | 如何共享依据、处理分歧，让纠正生效并发现跨分支联系？ | [报表排障中的多 Agent 延伸](surveyor/examples/03-depth-first-search.md) |

四个方向相互校正。全局空间帮助发现遗漏，真实诉求决定根节点，验证结果推动回退和扩树。协作贯穿这些判断，各分支仍按前三个方向深入，不要求每个任务都启动多个 Agent。

新证据、冲突和条件变化也能触发定向回看旧材料，形成此前未提出的问题，不必等树耗尽。尚未成题的联系可保留为线索；据此行动或下结论时，再进入原有假设验证。用户纠正则用于修正当前产物，并提炼有适用条件和反例的区别，在另一场景检验能否独立识别。

这些能力融入四个方向。开放探索可以交付新理解和有依据的问题；明确执行任务仍按原目标完成，不因发现旁支自动扩大授权，也不代替用户作其保留的思想裁剪。

协作共享目标、边界、来源与版本，并保留独立解释及未解决分歧。同源材料不能因多个模型转述而增加独立支持；关键纠正须体现在受影响分支的结论、产物或下一动作中。共同记录沿用现有任务文件，消息送达和全员同意不能代替理解更新或根目标验收。

默认沿最有价值的分支做深度优先搜索。每个关键节点都要有可检验的假设和否定条件。证据否定假设后，回退并选择剩余分支。

目标未达且已知树耗尽时，优先怀疑树不完整。检查根问题、遗漏的阶段、错误拆分和组合原因，再继续搜索。已知树耗尽不等于现实无解。

扩树须增加新的解释或可检验路径。已达到目标，或已有证据证明约束冲突时，如实收束。访问受阻也不能冒充假设已被否定。

复杂、长程或多分支探索必须在深入前建立可发现的本地状态，关键变化、回退和交接前写入并重读核验。已有任务文件可以复用，一次简短回答无需制造日志。中断、压缩或换会话后，从文件复核目标、授权和输入版本，恢复分支与下一动作，避免重复已失败路径。具体做法见[本地状态与恢复](surveyor/references/local-state.md)。

运行状态和证据留在任务本地，不进入公共 skill 仓库，不含密钥，未经另行授权不上传；普通本地文件不等于跨机器永久备份。

## 文件入口

- [SKILL.md](surveyor/SKILL.md)：四个方向及其联动规则。
- [逻辑空间](surveyor/references/logic-space.md)：建树、覆盖检查，以及从新旧材料发现问题。
- [真实诉求](surveyor/references/real-intent.md)：核验前提、环境适配、保留原意与纠正迁移。
- [深度优先搜索](surveyor/references/depth-first-search.md)：节点状态、回退和扩树。
- [本地状态与恢复](surveyor/references/local-state.md)：落盘入口、协作共享、纠正应用与中断后的继续方式。
- [自检清单](surveyor/references/checklist.md)：交付前的关键检查。

三个 demo 均包含输入、证据、判断和反例。演示数据均为虚构，不能作为真实系统的验证结果。

## 使用与安装

将完整的 `surveyor/` 目录放入目标环境的技能目录。替换已安装版本前保留备份。

Claude Code 可放在 `~/.claude/skills/surveyor`。其他环境按其技能加载方式安装。本方法不依赖特定工具。
