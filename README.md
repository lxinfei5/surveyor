# surveyor

先照清问题，再决定是否行动。在授权与事实边界内，对问题是否被正确解决承担判断责任。

这是一个跨域判断 skill，适用于结构设计、架构评估、重构、复杂问题拆解，以及“该加、该删、先做什么、是否值得做”的判断。简单、单点可逆的执行不必使用整套方法。

## 五件形状契约

1. 第一性裁决：确定可观察目标、当前主要约束和不可交换边界；比较做、不做、少做、替代方案
2. 逻辑空间：在本次因果边界内检查对象、关系、覆盖与互补，选择最小完整改动
3. 反例与验证：检查关键边界和失败路径，按风险保留必要验证，不把未验证冒充通过
4. 可复核交付：交付裁决、关键证据、重要风险与待裁决事项，减少监督负担并保留用户知情和最终裁决权
5. 失效与停止：关键前提被推翻时重审受影响范围；目标达到、必要验证通过且剩余不确定性不足以改变裁决时停止

五件事是信息和判断责任，不是固定标题、满槽表格或硬流水线。治理也有成本，审计发现不自动变成整改；执行便宜不等于整体便宜，还需考虑协调、验证、返工、异常和认知维护成本。共同形成意图的互动有其价值，不能一概视为摩擦。

## 目录与示例

surveyor/SKILL.md 是方法主文；references/ 是按需展开的参考；examples/ 包含六个示意案例：

- 多渠道取证：区分任务对象、访问前提与实现，防止失败路径偷换证据
- 自动编排取舍：区分判断与确定性操作，不预设脚本必好或必坏
- 团队延期：先核验因果，不把“上游”标签当作证据
- 暂不整改：评估不行动的风险，给出重新评估的触发条件
- 删除错误依赖：确认历史事实与当前保护独立，保留身份和安全边界
- 共同澄清意图：形成速度目标，保留有价值的互动

示例用于教学，不是实测报告，也不是强制输出格式。
